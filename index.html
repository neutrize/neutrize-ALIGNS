A · Attention — 知ってもらう
HPBのブログ・スタイル写真・検索でNEUTRIZEを見つけてもらう段階。ブログタイトルに「岡山 透明感カラー」「岡山 髪質改善」などを入れることでHPB内の検索順位が上がる。ブログ週3〜5本、スタイル写真週6枚以上が理想。
指標 → PV数 / ブログ投稿数 / スタイル写真枚数
キーワード → 岡山 美容室 / 岡山 透明感カラー / 岡山 髪質改善 / 岡山市北区 ヘアサロン
L · Landing — 止まってもらう
HPBの一覧でサムネイルを見た0.5秒でクリックするかスクロールするかが決まる。CVR 40%は業界51.9%より12pt低くNEUTRIZEの最大の弱点。
指標 → CVR（目標 51%以上）
I · Intention — 予約してもらう
ページを開いたお客様が予約ボタンを押すかどうか。クーポンの数・価格・紹介文の説得力で決まる。HPBアワード受賞・oggiotto全国上位1%認定は必ず冒頭に出す。クーポンは3本以内。
指標 → 新規客数 / 予約数 / 予約の埋まり具合
G · Gain — 体験してもらう
来店後の施術・接客・空間で「期待以上」を感じてもらう段階。GはNとSを自動的に上げる。ACR 16%はGが強い証拠。
指標 → ACR / 口コミ内容・ワード
N · Nurture — また来てもらう
一度来たお客様が継続的に来てくれるかどうか。口コミへの返信・HPBメッセージ・次回提案がここに効く。ACR 16%は業界平均の1.5倍。
指標 → ACR（目標15%以上）/ 口コミ件数
S · Share — 広めてもらう
満足したお客様が口コミ・紹介でNEUTRIZEを広めてくれる段階。口コミ件数が増えると検索順位も上がる。丁寧な返信がSをさらに加速させる。
指標 → 口コミ件数・評価点 / 紹介経由の新規客数
弱いフェーズは1つに絞る。全部同時に動かすと何も変わらない。ALIGNSは「どこを先に直すか」を決めるためのツール。
